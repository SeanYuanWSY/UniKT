# Batch 37（2026-10-06：LLM 信号的 pooled-AUC 可见性——Junyi 信号是否只是被 per-student 口径隐藏）

## 动机

batch28b 的方法学发现：Junyi LLM 三段粗分区真实且强（桶边际 0.547/0.706/0.811，跨度 0.26；学生内粗序 71.7%），但 per-student AUC 只计学生内跨桶对（仅 20% 可比对）→ pool_0 p=0.0647 差一步。自然反面检验：**换 pooled AUC（全体评估行一个 Mann-Whitney 池，跨学生计对）后，纯 LLM 表是否显著**？若 Junyi pooled p<0.05，则"LLM 零样本信号存在性"从 EdNet 单域升级为双域，且"可见性=度量选择"成为正式结论。

注：batch36 报告中"batch37 不立项"指其预注册门（删交界对重报 T1）未触发；本批是 T5 支线的独立新实验，不冲突。

## 实验设计（llm_pooled_visibility.py）

- 行集与 batch28 pool_0 **逐字一致**：尾-100 评估队列、A1 排除、`llm.get(kc,0.5)` 默认值、同缓存 k3_difficulty_cache.json。
- pooled AUC = 全体 kept 行的 pos×neg 全对比较（tie=0.5）。
- 置换零分布：重排 KC→LLM 值指派（200 次，rng 500+p，p=(#{≥real}+1)/201）——行集/学生构成固定，只随机化指派，控制跨学生构成混淆。
- 内置复现自检：per-student mean 必须复现 b28 三域锚（A17 0.5246 / EdNet 0.5496 / Junyi 0.5456，±0.0005），否则 assert 失败。

## 预注册裁决

- **主门（Junyi）**：pooled p<0.05 → T5 信号存在段升级"**pooled 口径下双域成立**（EdNet per-student + Junyi pooled；升级句同样受附门的跨学生混合混淆讨论义务约束）"；0.05≤p<0.1 → 边缘如实报，维持单域；p≥0.1 → Junyi 信号仅在边际/粗分区层面成立，可见性主张不升级。
- **附门（A17）**：预期不显著（粗分区不单调）；若反而显著 → 口径效应压过域结构，须在报告里讨论 pooled 口径的跨学生混合混淆后再用。
- **解释边界（预注册防过度声明）**：pooled 显著性只升级"信号存在"主张；**不重开注入主张**——注入评估是 per-student 口径，per-student 不显著意味着部署不可行仍然成立。两口径并存=评估方法学结论（LLM 知识评估须报 pair-share 分解 + 口径敏感性），不是"LLM 表可用"的翻案。
- 自检失败 → 全批作废重查。
