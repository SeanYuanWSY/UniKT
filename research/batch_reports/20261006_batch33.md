# Batch 33（2026-10-06：2×2 因子补格 + 近因曲线噪声种子稳健性）

## 动机

batch32 三层分解差一格：b29 全扰码=(F,F)、k=0=(F,T)、base=(T,T)，缺 **(T,F)**（证据真、holdout 标签扰）。补全后可检验两通道可加性；同时整条 k 曲线建立在单一噪声抽取上——k=1 下沉 0.005 的声明需要噪声种子稳健性。

## 实验设计（a17_factorial_noise.py）

- **A 部**：(ev=T, hold=F)，噪声 base 1000（与 b32 逐位兼容）。可加性残差 = 实测 holdout 损失 − b32 隐含值（AKT 0.0178 / DKT 0.0560）。
- **B 部**：k 曲线 × 噪声 base {1000,2000,3000}（rng base+uid%100000）。base1000 各 k 须逐值复现 a17_hist_recency.json（确定性自检）。k=inf 无噪声只算一次。

## 预注册裁决

- **可加性**：|残差|≤0.003 → 两通道独立可加（分解定稿）；残差 ≥+0.005 → 超可加（真证据放大滚动上下文价值——协同编码）；≤−0.005 → 次可加（冗余）。
- **下沉稳健**：k=1<k=0 在 ≥2/3 base × 两模型 → 边界不一致惩罚成立；否则降为"单噪声抽取现象"。
- **长程稳健**：全部 base 下 k=10 恢复 <50% → 长程结论冻结；任一 base 反转 → T2 措辞降级"跨噪声抽取主导倾向"。
- base1000 曲线若不逐值复现 b32 → 环境漂移警报，全批作废重查。

## 结果与裁决（19:58 factorial END，a17_factorial_noise.json）

**自检 ✓✓**：base_kinf = 0.5841/0.6331 精确；base1000 曲线双模型全 k 逐值 = b32 JSON。n=261 恒定。

**A 部（2×2 补格）**：

| 格 | idAKT | idDKT |
|---|---|---|
| (T,T)=base | 0.5841 | 0.6331 |
| (F,T)=b32k0 | 0.5707 | 0.5958 |
| **(T,F)=本批** | **0.5665** | **0.5497** |

- **AKT 可加（残差 −0.0002）**：实测 holdout 损失 0.0176 ≈ b32 隐含 0.0178，两通道独立，分解定稿。
- **DKT 超可加（残差 +0.0274 ≥ +0.005）**：真证据下扰 holdout 损失 0.0834 vs 扰码证据下仅 0.0560——滚动上下文的价值依赖真证据构建的循环状态（协同编码 +48%）。**架构分化：attention 可加 / RNN 协同**。另 (T,F)=0.5497 ≈ B1 0.548：毁滚动上下文后 DKT 精确落回查表水平。

**B 部（噪声稳健性，三 base）——修正 b32 一处超发**：

- **AKT 证据通道噪声脆弱**：k=0 三 base = 0.5707/0.5744/**0.5853**——base3000 抽取下全证据扰码几乎不掉点（损失 −0.001~0.013，均值~0.007）。b32 的"证据历史 0.0134"是单抽取，**AKT 证据通道降级为噪声级微弱效应**。
- **DKT 证据通道稳健**：损失 0.0373/0.0305/0.0341（~0.034±0.004）✓；k=10 恢复 <50% 三 base 全过 → **长程结论冻结（DKT）**。
- **k=1 下沉**：AKT 3/3 base 出现（−0.005/−0.007/−0.007）→ 边界不一致惩罚 **AKT 确认**；DKT 仅 1/3 → 降级单抽取现象（预注册门"两模型 ≥2/3"未达，如实记）。

**T2 修订版结论**（替换 b32 版）：滚动上下文 > 证据历史 a fortiori 成立——AKT 证据通道比 b32 以为的更小（~0.007 不稳定），DKT 稳定 0.034 且长程（k\*≈20-50）；两模型滚动上下文为主载体（AKT 0.0176 / DKT ≥0.056）；AKT 通道可加、DKT 协同。b29 的"86%/109% 抹除"幅度继承单抽取不确定性（方向与落点不变：抹后 ≈ 查表水平）。

**遗留单抽取数**：DKT 滚动上下文 0.0560 与协同 +0.0274 均来自 base1000 单抽取 → batch34 补 (T,F)/(F,F) × 三 base 硬化。
