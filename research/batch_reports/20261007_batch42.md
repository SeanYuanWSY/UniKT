# Batch 42（2026-10-07：能力排除臂无泄漏调参重跑——Codex #19 遗留闭环）

## 动机

Codex Run A P1-7 / 纠错 #19：`a17_ability_decompose_v2.py` 的调参存在标签回代——prior 用**全部** evidence 行拟合，而每第 5 行 evidence 又被用作调参伪 holdout，调参行的自身标签经 prior 回到自己的预测里（Codex 反例：α=1 选择集 AUC=1、α=0 为 0，即泄漏可完全支配选择）。当前正文已把该臂降级为"代理未被选中，不排除能力机制"（措辞层修复）；本批用无泄漏调参重跑，判定该臂是"干净排除"还是"真有信号"。

注：`ability_before` 本身无泄漏（hist 在预测后才 append）；v2 的唯一泄漏通道是 prior。v2 的 eval pass（真实 holdout）不受此泄漏影响——受影响的只是 α 的选择。

## 实验设计（`a17_ability_decompose_v3.py`）

1. **无泄漏调参先验**：调参行 = 每第 5 个非 holdout 非 A1 evidence 行（同 v2 规则）；`prior_tuning` 只用其余 evidence 行（全学生）拟合——调参行标签不可能进入 prior_tuning。
2. **选择**：调参行上 per-student AUC（prior_tuning + ability_before 混合，α∈{0,.25,.5,.75,1}）取均值最大者。
3. **评估**：α 冻结后跑真实 holdout（A1 排除）；`prior_final`=全量 evidence 重拟合（标准 tune-then-refit，holdout 未动）；另报 prior_tuning 敏感性与 α=0/α=1 两端点。
4. **v2 复现锚**：同批用泄漏 prior（全量）重跑选择——必须复现 v2 的 α*=1.0（三域）。

## 预注册门（写于运行前）

- **G1（排除确认）**：无泄漏 α*=1.0（边界）于 ≥2/3 域 **且** 最终 holdout delta(α*) ≤ +0.005 → 能力臂升级为"无泄漏调参同样拒绝该代理"；§5 措辞收紧（仍保留"不排除其他能力机制/更细代理"限定）。
- **G2（重开）**：无泄漏 α* 落内部（0.25–0.75）于 ≥2 域，**或** delta(α*) > +0.005 且方向一致 → 能力信号重开为候选载体；§5 重写，后续批次跟进（能力-通道交互设计）。
- **G3（复现锚）**：泄漏 prior 选择复现 v2 α*=1.0 三域全中；不中则先查实现差异再裁决。
- 两门互斥；单域异动如实记录不扩写。

## 裁决（v3.1 重跑，tag ability3b，2026-10-07 18:13）

| 门 | 判据（预注册） | 实测 | 结果 |
|---|---|---|---|
| G1 排除确认 | 无泄漏 α\*=1.0 ≥2/3 域 且 delta(α\*)≤+0.005 | α\*=1.0 **3/3**（交互完整 prior_tuning，均值 0.5370/0.5974/0.6098）；eval_final（prior_clean）delta=0.000 ×3（α\*=1 构造平凡，已披露） | **PASS（干净）** |

| G3 复现锚 | leaky 选择复现 v2 α\*=1.0 ×3；B1 锚 | selfcheck_v2_alpha ×3 true；eval_v2repro.B1=0.5481/0.5252/0.5624 == V2_B1_REF（selfcheck_v2_B1 ×3 true） | **PASS** |

**最终结论（两层限定版）**：在网格 {0,.25,.5,.75,1} 与学生内 AUC 准则下，**无泄漏（交互完整排除 + 无建表成员选择）调参 3/3 选择纯先验端点 α\*=1.0**——泄漏修复不翻转任何排序。实质证据：

1. **选择层**：α=0（纯能力）调参 AUC 三域全低于 0.5（0.4797/0.4838/0.4542），先验单调主导。覆盖 4136/2086/4121 调参行、269/212/173 有效学生（P2-5 已记录）。
2. **评估层**：α=0 端点臂纯能力 delta=−0.1541/−0.1887/−0.1742（n=261/245/213 配对；prior_clean）。
3. **泄漏量级（隔离测量，P2-4）**：prior_leaky_iso（同成员规则、仅调参行回代）对 α=1 调参均值影响 +0.0284/−0.0088/+0.0006——微弱、非单向、不翻排序。孪生行修复本身使 A17 α=1 均值 0.5512→0.5370（−0.014，即 v3 首跑被泄漏抬高的部分），EdNet/Junyi ≈不变。
4. **先验构造影响**：prior_clean vs 旧构造 B1 级漂移 +0.0004/+0.0011/+0.0044（与 batch41 G3 完全一致，跨批复现）；逐 KC 最大漂移 0.0087/0.1667/0.1231 为诊断量（稀 KC 单标签翻转）。

措辞（正文采用）："该标量能力代理（最近 ≤100 展开行中排除当前同题后的 ≤20 个作答行；多 KC 作答可重复计权）在无泄漏调参下仍三域一致未被选中、纯能力端点显著为负"——**不外推到**更细能力表征、全局能力异质性机制或池化准则（后者曾选 α=0.75）。"干净排除"仅在上述网格/准则/代理限定下使用。
