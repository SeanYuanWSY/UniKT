# Batch 40（2026-10-06：pooled 口径 plug-in 复现功效——b39 的对偶）

## 动机

b39 定论 per-student 三域全为边界现象（复现功效 ≤0.48 at N=400，结构性原因=置换秩对队列扩大稳健）。对偶问题：**pooled 口径（b37：Junyi ge=2、EdNet ge=4，远离 α 界）的 plug-in 复现功效是否高**？若 Junyi/EdNet ≥0.8 而 A17 低，T5 诚实边界收口为干净对照："pooled 发现稳健、per-student 边界"。

## 实验设计（llm_pooled_power.py）

- 与 b39 同设计（学生 bootstrap B=400，N∈{30,60,n_scored,120,200,300,400}，N80 网格值，observed-effect plug-in + bootstrap 外推警示），统计量换 pooled AUC（tie-averaged 秩法=Mann-Whitney tie=0.5 的精确等价实现）。
- 置换族=b37 原族（rng 500+p，zip 形式映射）——**双自检：全队列 pooled AUC 复现 b37（0.5321/0.5893/0.6645）；全队列置换 p 复现 b37（0.1244/0.0249/0.0149，±1/402）**。
- 实现注记：预计算每生 (kc_index, y) 数组，draw=两次 concatenate，每指派预测=一次 fancy-index gather（无 Python 行循环入 bootstrap 内层）；预计 ~15 分钟。
- 未覆盖 KC（kc_index=-1）经 np.where 置 0.5——与 b37 的 `assign.get(k,0.5)` 语义一致。

## 预注册裁决

- 主预期门：Junyi 功效(N≥n_scored)≥0.8 且 EdNet ≥0.6 → "pooled 稳健 vs per-student 边界"对照成立，T5 收口。
- Junyi <0.6 → pooled 发现也降级边界级，T5 全线诚实降级（如实报）。
- A17 对照：预期低（ge=24/200，效应 0.5321）——若 ≥0.6 则复核。
- **注意**：本批功效高≠pooled 口径"更有价值"（b38 已定 pooled≈全局边际对齐视）；结论只用于稳健性分层，不重开注入。
- 自检任一失败 → 全批作废重查。

## 结果与裁决（pooledpower END 12 分，llm_pooled_power.json）

| 域 | pooled（复现锚） | ge/p 复现 | power: N=30→100→400 | N80 |
|---|---|---|---|---|
| Junyi | 0.6645（=b37） | 2 / 0.0149 逐位 | 0.635→**0.943**→1.0 | **60** |
| EdNet | 0.5893（=b37） | 4 / 0.0249 逐位 | 0.495→0.65→0.935 | **300** |
| A17 | 0.5321（=b37） | 24 / 0.1244 逐位 | 0.22→0.193→**0.125（降）** | >400 |

**裁决：主预期门过（Junyi 0.943≥0.8 且 EdNet 0.65≥0.6）——"pooled 稳健 vs per-student 边界"对照成立，T5 诚实边界收口**：

1. **Junyi pooled 发现极稳**：N80=60（现队列 100 的六成即可复现），N≥300 功效 1.0——与 per-student（N80>400、曲线平坦 0.24）形成最强对照。同一张表、同一批学生：**结论的稳健性完全由度量口径决定**。
2. **EdNet pooled N80=300**：现队列 0.65，3 倍队列可到 0.9+——稳健但弱于 Junyi（ge=4 vs 2）。
3. **A17 曲线随 N 下降（0.22→0.125）**：b39 的结构性论断（N→∞ 功效收敛 0/1 阶跃）的直接实证展示——plug-in 真值 p=0.1244>α，队列越大越确定地"不显著"。这也给 b39 的平坦曲线补了第三种形态（上升=界内真效应、平坦=骑界、下降=界外）。
4. 按预注册护栏：本批只做稳健性分层，**不重开注入、不升级 pooled 的价值主张**（b38 已定 pooled≈全局边际对齐视）。
5. n_students=100/域（pooled 不需要学生内两类齐全，无 None 过滤——与 b37/b38 的 n_rows 口径一致，与 b39 的 95/83/82（per-student 口径）不同属设计而非 bug）。

> **勘误（2026-10-07，Kimi Code 补审）**：①"直接实证 0/1 阶跃"降级为"与 α/1 渐近一致的实证展示"（7 点网格停在 0.125，零效应侧收敛到 10/201≈0.05 而非 0）；②功效点含 B=400 蒙特卡洛噪声（±0.05 量级），EdNet N80 的 200/300 网格值在噪声内不可区分，N80 应报网格值。结论不变，见 PAPER_NUMBERS_V2 自我纠错史 #10。

## 二次勘误（2026-10-07 追加，Codex / 纠错 #15、#20）

①同 batch39 二次勘误：`llm_pooled_power.py` 为固定置换族下的学生 bootstrap 拒绝频率，N→∞ 极限 = 1{p_full≤.05}（pooled p_full=.1244/.0249/.0149 → A17 极限 0、EdNet/Junyi 极限 1）；"A17 下降曲线=α/1 渐近实证"更正为"与 p_full=.1244 对应的指示极限 0 相容"；Junyi N≥300 达 1.0 与极限 1 相容。②口径对照补注：per-student（rng 200+p）与 pooled（rng 500+p）的 MC 指派不同，"翻转/分层由口径决定"应读作"随口径（联合更换指标与 MC 指派）翻转/分层"，口径变量未单独隔离。③"复现功效"措辞统一降级为"同池同族 bootstrap 拒绝频率"。
