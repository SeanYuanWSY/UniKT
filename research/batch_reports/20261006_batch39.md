# Batch 39（2026-10-06：per-student 功效曲线——Junyi 不显著是没信号还是没功效）

## 动机

b28/37/38 后 T5 定稿为三口径故事，其中 per-student（部署口径）Junyi 0.5456 p=0.0647 差一步（n=82 生）。遗留的诚实边界问题：**这个"未过"是效应不存在，还是队列功效不足**？本批用已有行集做功效曲线定量收口——若 N80 在可达范围（≤400），写法是"underpowered"；若 >400，写法是"信号不足以在合理队列规模下检出"。

## 实验设计（llm_perstu_power.py）

- 行集与 b28/37/38 逐字一致（尾-100、A1 排除、`llm.get(kc,0.5)`）；R[生]=真实指派 per-student AUC。
- **置换零分布逐位复现 b28**：同 rng 200+p、同映射形式 `assign[kcs[sh[t]]]=vals[t]`（非 b37 的 zip 形式——两者分布等价但抽样不同，本批要求精确复现）。
- 功效：B=400 学生 bootstrap（有放回）；每次抽 N 生，stat=R 均值，null=同批学生在 200 置换下的均值，p_b=(#{null≥stat}+1)/201；power=P(p_b<0.05)。N∈{30,60,n_scored,120,200,300,400}，N80=最小 power≥0.8 的 N。
- 双自检：真实均值复现 b28 锚（±0.0005）；全队列置换 p **逐位**复现 b28（±1/402）。
- None 对齐注记：stratified_auc_rows 的 None 只由 y 类缺失决定（与指派无关），评分学生集在真实/置换间恒同。

**裁决：主门第三档（Junyi N80>400）——"效应量不足以在合理队列规模检出"，T5 维持 per-student 口径 EdNet 单域显著；且本批有一个超出预注册的结构性发现**：

1. **"underpowered"假设被否**：Junyi 功效曲线平坦（0.21→0.24，N×5 无增长）——不显著不是 82 生太少，而是 plug-in 效应（p=0.0647）正卡在界上：draw 级 ge 要从 12 压到 ≤9 才过 0.05，学生重抽噪声做不到。**错过是真实的（在该口径/该效应量下）**。
2. **结构性原因（方法学发现）**：置换检验的检验统计量=真实指派相对 200 个置换的**秩**；秩对队列扩大稳健（每个置换的总体均值 μ_j 与真实总体均值的大小关系由 KC 指派决定，非由 N 决定）→ N→∞ 时 draw 级 p 收敛到总体秩 p，功效收敛到 0/1 阶跃而非上升曲线。B=200 离散检验在 α 附近的复现功效有界且低。
3. **EdNet 自身复现功效仅 0.30(n=83)→0.48(400)**——已显著的 EdNet 结果同属边界级。预注册软门"中等偏上"实测偏低，如实记录（学生级交互噪声+离散秩）。**T5 措辞精确化（非翻案）**：EdNet per-student 显著性标注"边缘（p=0.0448，plug-in 复现功效≈0.5）"；三域 per-student 全部为边界现象。
4. A17 平坦 0.16-0.22 与 N80>400 预期一致（无信号）。
5. 外推警示按预注册：N>82/83/95 为 bootstrap 外推（observed-effect plug-in）。

**T5 方法学注记增补**：报告 exact ge（已做）+ 200-perm 离散检验在 α 附近功效受限——近界结果应报复现功效或至少 exact p，避免把 p=0.045 读成稳定效应。
