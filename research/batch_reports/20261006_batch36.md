## 勘误（2026-10-07 追加，Codex Run A P0 / Run B F2 / 纠错 #13）

本报告的"残余泄漏上界"解释作废：tie=0.5 下 AUC(1−p)=1−AUC(p)，确定性攻击族须含取反——对称闭包最大值为 A17 0.5391（1−0.4609）、EdNet 0.5570（1−0.4430）、Junyi 0.5141（不变）。"≤0.514 上界"与"上界<差距 12%"两主张撤回；取反收益来自保留行真实重做反相关（合法历史），高于 0.5 不证明泄漏。可保留：正向复制无信号、withA 阳性对照、removed 构造确认三组数字不变；对称闭包仍低于 A17 本域深度 0.584/0.633（余量收窄、方向成立）。本 JSON 数字本身全部正确，错误在"上界"这一解释层。
