# Batch 69（2026-10-12：M1 转移表复活首测——A1-only 干净口径，纯表格评估零训练）

## 动机

b68 复活扫描的候选#2。M1（马尔可夫转移表）当年死于 artifact 重定基——其 withA 数字（0.73-0.94）被证膨胀，idea 整体关闭；但 **A1-only 协议当时还不存在**，转移表从未被干净口径公平审判。机制假设真实存在：B1 是 KC 一阶边际，学生条件化转移动态（上次答对→本次同类答对的持续性）是 B1 结构性看不见的信息。若干净口径下仍有增益 → 查表家族内部有未挖的一阶结构；若零增益 → "KC 边际足够"主张更强。两个方向都对论文有利。

## 设计（`m1_retry_a1.py`）

三域 × 纯表格评估（无深度模型，零 GPU）：转移表 T(y_t | kc_t, kc_{t-1}, y_{t-1}) 由 [:300] 池 evidence 行构造（run-complete 规则与全部公平评估一致；单元格 n≥3 保留，Laplace(1,2) 平滑）；holdout 评分行排除 A1（与全部公平评估同）；转移单元格缺失时回退 B1 边际（fallback 即假设检验的保守方向——增益只能来自有证据的转移格）。对照 = **同评分行上的纯 B1**（same-support 配对，stratified AUC，cluster bootstrap B=5000 seed=0）——即"转移表 vs 自己的 B1 底座"，不是 vs 旧参考。锚：n_kc_prior_b1 == {96,175,38}（三域 B1 表结构与全部既往批次一致）；n_nonfinite=0。哨兵 M1RETRY-DONE / -ANCHOR。

## 预注册门（写于排队前）

- **G1（健康+锚）**：三域 n_anchor_pass=3/3；nonfinite=0；n_trans_kept 与 n_trans_raw 落 JSON 供支持量判读。
- **G2（主门，delta = markov+fallback − B1，逐域）**：
  - **G2-a（复活）**：任一域 delta CI95 下界 > +0.005 → M1 在干净口径下复活，进入正式 idea 流（下一批扩四域×种子）；
  - **G2-b（维持关闭）**：三域 CI 均含 0 或下界 ≤ +0.005 → **关闭维持且升级为"干净口径下终审关闭"**——死因从"artifact 主导"改写为"artifact 主导 + A1-only 下无增益"，正文 B1 足够性主张加强；
  - **G2-c（反向）**：任一域 CI 上界 < 0（转移表显著更差）→ 记录"转移噪声有害"注记，关闭同 G2-b。
- **G3（记录）**：n_trans_kept 三域分布（转移格支持量）；fallback 占比（无证据格行数比例——若 >80% 则 G2-b 的"关闭"要限定为"证据格稀疏条件下的关闭"）。
- **限定**：[:300] 队列、单种子口径（表格构造无随机性，bootstrap seed 固定）、三域 5000 采样、n≥3 与 Laplace 为先验指定（未调参）；转移表未与深度模型对照（本批只测查表家族内部）。
