# Batch 70（2026-10-12：M1 跨题转移表——b69 缺陷修正版，纯表格评估）

## 动机

b69 暴露的实现-设想错位（外部复盘指出）：建表条件 `rid[i-1]==rid[i]` 按 question 分段——**表只学到了同题段内相邻转移（artifact 通道的结构位置），跨题转移从未入表**；且未记录命中率，EdNet 的 delta=0 无法区分"无信息"与"没查到"。本批修正两处：①建表 = 相邻行且 **question 不同**（跨题段）且两行均 evidence；②命中率字段（n_hit_rows/n_fallback_rows/hit_rate）必落 JSON。这才是 M1 复活假设（跨 KC 学生条件化动态）的正确实现。

## 设计（`m1_retry_cross.py`）

母本 = b69 脚本，仅改建表条件（跨题）+ 命中率计数，其余（n≥3、Laplace(1,2)、run-complete 证据、A1-only 评分、same-support B1 对照、boot 5000 seed0、锚 96/175/38）逐行不动。哨兵 M1XRETRY-DONE / -ANCHOR。

## 预注册门（先冻结，再 scp，再入列）

- **G1（健康+锚）**：三域 anchor 3/3；nonfinite=0；**hit_rate 必须非零可读**（若三域 hit_rate 全 <5%，G2 的关闭判读自动附加"跨题证据格在本采样下不可得"限定——即 M1 死于数据结构而非信息不存在）。
- **G2（主门，delta = cross-markov+fallback − B1）**：
  - **G2-a（复活）**：任一域 CI95 下界 > +0.005 且该域 hit_rate ≥ 20% → M1 复活进正式流（增益+命中率双条件，防"稀疏幸运格"）；
  - **G2-b（终审关闭）**：三域 CI 含 0 → **M1 干净口径终审关闭**（同题段版 b69 + 跨题版本批双杀），正文"B1 一阶边际足够"主张加注脚；
  - **G2-c（有害）**：任一域 CI 上界 < 0 → 转移噪声有害注记（与关闭并存）。
- **G3（记录）**：hit_rate 三域分布；trans_kept 跨题版支持量（预期远小于 b69 的 814/453/69——跨题 (kc,kc',y') 组合更稀疏）；与 b69 同域 delta 对照。
- **限定**：[:300] 单采样；n≥3/Laplace 先验指定未调参；命中率条件 20% 为预注册指定；不与深度模型对照。
