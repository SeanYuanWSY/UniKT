# Batch 43（2026-10-07：batch41 先验的孪生行泄漏核查——Codex batch42 审查 P1-1 传播面）

## 动机

Codex batch42 审查发现 v3 的 `prior_tuning` 存在孪生行泄漏（多 KC 展开的一次作答=若干连续同标签行，按索引排除调参行后其孪生行仍留在先验里）。同日核查确认：**batch41 的 `prior_fixed`（t1_fair_rescore.py:79-86）同样只按索引排除 holdout 行**（`if i in hold: continue`）——holdout 交互的孪生展开行携带该 holdout 答案标签留在先验中。本批量化该泄漏对 batch41 主表结论的影响。

影响面预判（写于运行前）：泄漏需要 (a) 多 KC 展开题目、(b) holdout 含此类行、(c) 孪生 KC 出现在被评分行。batch41 已测的成员选择修复（prior_old→prior_fixed）漂移 ≤0.0044；孪生行残留是更小的构造变化（每 KC 一两个标签之差），预期漂移更小，但**必须实测，不能假设**。

## 设计（`t1_fair_rescore.py` t1fair3 补丁）

- `prior_fixed2` = 证据级成员（全部学生非 holdout 证据）+ **holdout 题目 run 完整排除**（`run_ids`：极大连续同题块；holdout 行所在 run 的所有行都排除）。
- 诊断：`sibling_drift_max_abs`（prior_fixed2 vs prior_fixed 逐 KC 最大漂移）、`B1_sibling_drift_full_mean`（全子集 B1 均值漂移）。
- 主判定：每格同支持集配对 delta 用 prior_fixed2 重算（`delta_fair_B1_minus_deep_rc` + `ci95_fair_rc`），与 batch41 原字段并排。
- 其余逻辑（deep 侧、对称闭包攻击、selfcheck）不动；原 selfcheck 必须继续全过（复现性）。

## 预注册门（写于运行前）

- **G1（结论稳健）**：prior_fixed2 下 5 个显著格（A17 AKT/DKT、EdNet AKT、Junyi AKT/DKT）的 `ci95_fair_rc` 仍全部不含 0 → batch41 主表结论维持，PAPER_NUMBERS 补脚注（孪生漂移实测值）。
- **G2（实质变化）**：任一显著格 `ci95_fair_rc` 跨零 → 主表对应格降级，batch41 勘误。
- **G3（复现）**：既有 selfcheck（B1_old vs t1、copy vs b36、neg identity）全过；`sibling_drift_max_abs` 记录但无门（诊断量）。
