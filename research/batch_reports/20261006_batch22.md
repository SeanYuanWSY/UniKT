# Batch 22（2026-10-06：A17 深度优势机制分解——v1 P0 废弃 → v2 重写部署）

## 动机

A17 是本域深度模型唯一存活域（idAKT 0.584 / idDKT 0.633 vs 查表 B1 0.548）。问题：深度优势来自学生异质性（滚动能力）还是序列交互？若 B1+单标量能力估计能收窄大半差距 → 前者。这是 PS-0 之外解释"查表缺什么"的直接探针。

## v1 判 P0（审查员裁定，17:0x）

三项缺陷：
1. **退化（P0）**：`stratified_auc_rows` 是学生内 AUC；v1 的 ability 用证据段滚动窗，holdout（连续尾段）期间 hist 不增长 → ability 在整个 holdout 段每学生一个常数 → 学生内 pred 排序与 B1 完全相同 → delta 数学恒等于 0。探针只能产出假阴性。
2. **标签泄漏（P1）**：alpha 选择收集了 holdout 行进 ev_rows，且用池化 AUC 准则，与评估的学生内均值准则错位。
3. **低效（P2）**：alpha_star 在学生循环内重算，1.5-5 小时。

v1 输出仅作废案注脚（预期 delta≈0，恰为 P0 的实证）。另：主代理重写 v2 首版时又埋了同一退化（else 分支只入非 holdout 行，holdout 前缀仍进不了窗），自查发现后修复——退化类错误两次出现，证明"每实验必审"纪律必要。

**P0 实证（17:30 v1 部分输出）**：A17 delta = **-0.0014**（≈0，与审查员的数学预言一致：holdout 段常数 ability → 学生内 AUC 不变）；B1_A1excluded 0.5481 精确复现 t1ci B1 锚（协议无漂移，坏的只是探针本身）。EdNet/Junyi 部分待 v1 跑完补齐。

## v2 修复（a17_ability_decompose_v2.py，审查通过）

- ability 时变：所有行（含 holdout 前缀、A1 行）都入 hist 窗；同题前行按行动态剔除（`ability_before`，与 batch19 sanitize_nodelete 的 keep_pos 同构切 artifact 通道）。
- alpha 选择：证据段每第 5 行伪 holdout（跳过 A1），每生独立 stratified AUC，按学生内均值准则选；alpha_star 每域一次，eval pass 前冻结。零 holdout 标签接触。
- B1 基线（rows1）与 t1_paired_ci 协议逐位同源 → B1_A1excluded 可交叉验证 t1ci B1_mean。
- 审查确认 holdout 连续尾段契约（restore.py:180-188），时变修复真实生效；效率降至分钟级。

## 预注册裁决（主指标 = B1_plus_ability − B1_A1excluded，A17 主域）

- **异质性主导**：A17 delta ≥ +0.020（相对 0.548 收窄 ≥1/3 到 0.584 的差距：需 ≥+0.012，取保守 +0.020）→ "深度优势=学生异质性"，写入机制分解，B1 增强方向立项。
- **部分贡献**：+0.005 ~ +0.020 → 异质性是分量之一，写 T3b 注脚，关闭。
- **无贡献/负**：< +0.005 → 序列交互主导（或能力窗太粗），关闭；对照域 EdNet/Junyi delta 同报。
- 附带 sanity：alpha=1.0 时 delta≡0；v2 与 v1 的 B1_A1excluded 应逐位一致（漂移检查）。

## 结果与裁决（17:4x 裁定，v2 = a17_ability_decompose_v2.json）

| 域 | alpha_star | B1 | B1+ability | delta |
|---|---|---|---|---|
| A17 | **1.0** | 0.5481 | 0.5481 | 0.0 |
| EdNet | **1.0** | 0.5252 | 0.5252 | 0.0 |
| Junyi | **1.0** | 0.5624 | 0.5624 | 0.0 |

**主裁决：无贡献分支，batch22 关闭。** 三域证据段伪 holdout（学生内均值准则）一致选 alpha=1.0（纯 KC 表，能力权重 0）——全局滚动能力标量在主口径准则下零增益 → A17 深度优势**不是**学生全局异质性可解释的，判"序列交互主导"（预注册 < +0.005 分支）。

机制注脚（两条，与既有发现拼图吻合）：
1. **对照 b234 B3**：KC 条件化近期性（该生该 KC 最近 5 次）在 EdNet 有效（0.534 vs B1 0.525）——可提取的学生信号是 **KC 条件化**的，不是全局能力。全局标量 vs KC 条件化的分野与 IDEA-2 校准之死（AUC 保序不变性家族）同谱系。
2. **准则敏感性诚实注记**：v1 的（泄漏的）池化准则曾选 alpha=0.75——学生间水平位移在池化 AUC 下可见、在学生内 AUC 下按构造不可见。我们全部主数字（含 idAKT 0.584）都是学生内口径，故"全局能力不解深优势"结论限定在主口径内；跨学生校准类收益从未在本项目口径中计分。

B1 锚三域精确复现 t1ci（0.5481/0.5252/0.5624）；v1 废案三域 delta≈0（-0.0014/+0.0004/0.0）作为 P0 退化实证存档于 a17_ability_decompose.json。
