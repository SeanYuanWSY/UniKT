## 四、口径与纪律（读数字前必知）

- **A1-only 主口径**：删"同题相邻异 KC"行（explode 嫌疑）；Junyi 无此类行两口径同值
- **公平配对**：same-support（同一评分行两侧同评）+ 学生级配对 + cluster bootstrap B=5000
- 预注册门先行：每批门在排队前冻结，裁决按门执行，门写错如实记录（b57/b67 案例）
- 措辞纪律：CI 跨零=等效；点估计不翻转=欠训练排除；"未检出"≠"不存在"（b70/b71 两次 advisory 修正的教训）
